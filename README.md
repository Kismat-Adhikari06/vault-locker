# VaultLock

A lightweight folder locking application for Linux desktops.

## Description

VaultLock provides a simple, clean interface for managing folder security on Linux.

## Dependencies

- Python 3.10+
- GTK 4.0
- libadwaita 1.0
- PyGObject

## Running

```bash
cd vaultlock
python3 main.py
```
